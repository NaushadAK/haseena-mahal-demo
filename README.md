# Haseena Mahal — tailoring system demo

Clickable demo of the tailoring management system for Haseena Mahal Tailors & Uniforms, used to walk the client through each screen and freeze the requirements.

- Everything runs in the browser from `index.html`; there is no server or database.
- All customers, orders and figures are **sample data**.
- Use "Signed in as" at the top to switch between Sales, Accountant, Branch admin, Management and Tailor views.
- "Questions for you" lists the open decisions; answers stay in the viewer's browser.
